# Examples

Three pieces, each a folder exactly like a group's final project: `score.json` plus `audio/`. They're listed first in the conductor's menu, and the conductor opens on *Crickets*.

| Folder | What it shows |
|---|---|
| `crickets/` | One short sound passed between four groups on a tight grid, as one-shots (`"loop": false`); group B goes through a low-pass filter swept by an LFO. |
| `effects-testing/` | One cowbell through a different effect chain in each group: delay, high-pass, feedback delay, reverb. |
| `ptc-01/` | Six sounds entering one by one, each group drifting (`"ratio": 1.01`), with one-shots and loops; about six minutes. |

Open any of them in the score editor (*Open an example or a project…*) to see the events as forms and preview them.

*Crickets* and *PTC 01* use sounds originally generated by the instruments of Productions Totem Contemporain, and carry that credit in `credit`.
